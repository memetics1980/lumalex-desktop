# LumaLex macOS 安装与使用

[简体中文](MACOS_GUIDE.zh-CN.md) | [English](MACOS_GUIDE.en.md) · [返回项目介绍](../README.md)

## 下载与安装

从 [macOS build 88 Release](https://github.com/memetics1980/lumalex-desktop/releases/tag/v0.1.0-build88) 下载 DMG 或 ZIP。需要 macOS 12 或更新版本。包内包含 Apple Silicon 和 Intel 架构，当前已在 Apple Silicon 上测试，Intel 尚未实机验证。

1. 打开 DMG，将 `LumaLex.app` 拖到“Applications / 应用程序”，然后弹出磁盘映像。也可解压 ZIP，把其中的应用复制到“应用程序”。
2. 从“应用程序”打开 LumaLex。更新前先用 `⌘Q` 退出旧版，再替换应用。
3. 预览版采用临时签名，尚无 Developer ID 签名和 Apple 公证。如果系统提示无法验证开发者，请核对下载来源，然后按照 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中确认“仍要打开”。无需关闭系统整体安全保护。
4. 在“词典”页导入自己的 MDX/MDD 文件夹。配套资源留在原文件夹，不随应用分发；不要移动或删除已导入的源文件。

下载页提供同名 SHA-256 文件，可在终端运行 `shasum -a 256 下载的文件名`，与校验文件比较。

## 屏幕取词与辅助功能权限

在“设置 → 屏幕取词”中开启功能，选择全局快捷键。默认 `⌘⌥L`，也提供 `⌘⇧L`、`⌥Q`；如与其他应用冲突，请改用其他组合。

首次使用，在“系统设置 → 隐私与安全性 → 辅助功能”中添加并启用“应用程序”里的 `LumaLex.app`。设置页的“在 Finder 中显示当前应用”可以定位实际运行的副本。授权后用 `⌘Q` 彻底退出并重开。

从 build 95 起，设置页也支持“自定义快捷键…”：按下 ⌘ 或 ⌥ 搭配字母、数字或 F1–F11，可加 ⇧。录入期间暂停全局取词，取消后恢复原键；冲突时保留原设置。当前公开 build 88 仍使用上述三个预设。

在浏览器正文中选中单词，再按所选快捷键。Edge / Chrome 首次启用网页辅助功能接口可能多等待约两秒。若来源应用提供语境，浮窗可显示 AI 功能；若只能复制选中词，会标明“兼容复制模式”，只查本地词典。复制模式会更新系统剪贴板。密码字段不取词，也不使用 OCR。

**更新后仍提示权限不足**：临时签名会随二进制变化，旧授权可能不适用于新版。移除辅助功能列表中的旧副本，重新添加当前应用、启用权限，再退出重开。开发测试版使用独立标识，不代表发布版已授权。

## 浮窗与菜单栏

- 通过词典名称按钮或左右箭头切换；选择分组后，切换限定在该范围内。
- 按住顶部单词标题或空白处拖动；箭头到达范围边界时会禁用。
- “自动关闭”在鼠标离开浮窗五秒后关闭；“持续显示”保留浮窗。AI 请求进行中暂停自动关闭。
- 发音需要词典附带对应资源。收藏与主窗口词汇本共用。
- 在“设置 → 关闭主窗口时”选择隐藏到菜单栏，点击 X 后可以从顶部菜单栏图标恢复。启用屏幕取词时，程序需要在后台继续运行。用菜单栏的退出项或 `⌘Q` 完全退出。

## 词条选择与词形（build 95 起）

主窗口词条选区右键提供统一的“复制／查词”，双击正文中的单词直接查词，发音控件和已有词条链接保持各自行为。

浮窗先在当前范围查原词，未命中时再尝试有限的相关词形。原词与相关原形可主动切换；切换后标题、收藏及返回主窗口使用当前词形。短语仅提供主词候选时，需要点击“查看主词”，不会把单词释义当成整个短语的释义。词形回退不调用 AI，AI 仍依据原选词和原句。

## AI 语境释义

在设置中填写兼容 API 地址、模型和 API Key，保存并测试连接。密钥保存在 macOS 钥匙串中。取词浮窗得到语境后，主动点击 AI 按钮；只配置 AI 不会自动分析所有选区。

AI 请求会发送选中词和最多约 500 个字符的附近语境到配置的服务。“测试连接”也发送示例请求。普通词典查词离线完成，词典不会整本上传。不要发送敏感内容；输出需要对照词典核实。

## 数据与现有限制

设置、索引和学习记录存放在当前用户的 Application Support 目录，独立于应用包。替换应用包通常不删除这些数据。macOS 与 Windows 不会自动同步数据或密钥；换电脑时请导出学习数据，另行准备词典，并重新配置 AI。

主窗口词典、分组、收藏、复习和学习数据导出操作可参考 [完整使用说明](USER_GUIDE.zh-CN.md)；其中安装、托盘和 Windows 快捷键部分以本指南为准。

浏览器、文档与 PDF 阅读器的辅助功能接口不同；某些页面或 PDF 只能兼容复制取词。此版尚未完成 Intel 和所有 macOS 版本的实机验证，也未经过 Apple 公证。
