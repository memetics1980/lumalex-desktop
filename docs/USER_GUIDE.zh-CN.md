# LumaLex Windows 使用说明

[简体中文](USER_GUIDE.zh-CN.md) | [English](USER_GUIDE.en.md) · [返回项目介绍](../README.md)

本说明面向 Windows 10/11 的 64 位便携版。LumaLex 是词典阅读器：需要自行准备合法可用的 MDX/MDD 词典，AI 是可选辅助，不是离线词典的替代品。

## 1. 首次启动与导入词典

1. 完整解压便携包，运行 `LumaLex.exe`。EXE、DLL 和 `data` 文件夹必须在一起。
2. 如果词条页面空白，先确认 Microsoft Edge WebView2 Runtime 已安装。
3. 在“词典”页面点击“导入词典”，选择词典所在文件夹。
4. 保持 MDX 与配套 MDD 在同一位置，例如：

```text
MyDictionary/
  MyDictionary.mdx
  MyDictionary.mdd
  MyDictionary.1.mdd
  MyDictionary.2.mdd
```

MDX 提供词条，MDD 提供音频、图片、字体等资源。有些词典另附 CSS/JS 等文件，请保留完整词典文件夹。没有配套资源时，文字可能可读，但发音或图片可能缺失。

导入后不要随意移动、重命名或删除原文件。初次导入或源文件变更时可能需要建立索引。文件位置改变后，请重新导入；程序不会修改原始 MDX/MDD。

## 2. 主窗口查词与分组切换

在“查词”页面输入单词并确认查询。找不到精确词形时，程序可能尝试词形变化或相近拼写，并提示实际显示的单词，请留意提示。

在“词典”页面设置显示名称、启用状态、顺序及分组。查词时可选择“全部词典”“未分组”或某个分组；选择具体分组后，查找和左右切换只在该范围内进行，不会自动跳到其他组。

切换方式：

- 点击词典名称，打开选择列表。
- 使用左右箭头，按当前范围内的顺序切换。
- 宽窗口可使用左侧词典列表；紧凑时可从词典入口展开列表。
- 在主窗口使用 `Ctrl + PageUp` / `Ctrl + PageDown` 切换前一本/后一本词典。

点击词条内部跳转链接可以反查相关单词。选中文字后，右键菜单中的“复制”和“查词”用于复制选区或发起新的查询。词条内喇叭按钮是否能播放真人音频，取决于词典是否附带对应音频资源。

### 常用主窗口快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + L` | 聚焦查词输入框 |
| `Ctrl + D` | 收藏或取消收藏当前词条 |
| `Ctrl + ← / →` | 词条浏览历史后退 / 前进 |
| `Ctrl + PageUp / PageDown` | 切换前一本 / 后一本词典 |
| `Esc` | 关闭当前临时界面，具体行为取决于焦点 |

词条浏览历史的后退/前进与切换词典是两种不同操作。快捷键可能受当前控件或词典页面焦点影响。

## 3. 屏幕取词：在阅读中打开浮窗

### 开启与使用

1. 进入“设置 → 屏幕取词”，启用“全局快捷键取词”。
2. 默认快捷键是 `Ctrl + Alt + L`；设置中还可选择 `Ctrl + Shift + L` 或 `Alt + Q`。
3. 保持 LumaLex 运行，在其他应用中选中单词或短语。
4. 按快捷键，在光标附近查看查词浮窗。

如果提示快捷键被占用，可以先关闭开关、改选快捷键，再重新开启。主程序彻底退出后，全局取词不再工作；需要后台取词时，可选择关闭主窗口后“隐藏到托盘”。

### 浮窗里的操作

- **切换词典**：使用 `[◀] [当前词典 ▾] [▶]`。点击名称打开可滚动的分组列表，选择查找范围和词典；左右箭头只切换当前范围内的词典。
- **收藏**：点击星形按钮收藏/取消收藏，记录与主窗口词汇本共享。
- **发音**：点击词条里的喇叭，播放词典配套音频。
- **返回主界面**：点击“主窗口”，继续在完整查词页面查看当前单词。
- **移动位置**：按住顶部空白区域拖动，可用鼠标或触摸；按钮和词条正文不作为拖动区域。
- **自动关闭**：光标在浮窗内时保持打开；移出后 5 秒自动消失，移回可继续阅读。
- **持续显示**：点击显示模式按钮切换为“持续显示”，取消自动关闭；可手动关闭或切回“自动关闭”。
- **AI 等待**：AI 请求进行中暂停自动关闭。手动关闭不受此保护限制。

### 支持哪些应用？

| 使用场景 | 取词方式 | AI 语境释义 |
| --- | --- | --- |
| 普通网页、提供可用 Windows 文本接口的应用 | 读取选区，尝试获取附近语境 | 配置完成且语境可用时支持 |
| 部分 PDF 阅读器及不兼容应用 | 兼容复制模式，只查询选中文字 | 不支持，因为没有上下文 |
| 扫描图片、禁止复制的文档 | 可能无法获取文本；目前不是 OCR 取词 | 不支持 |
| 密码输入框 | 不读取 | 不支持 |

不要假定所有浏览器 PDF 或所有阅读器表现相同：具体取决于文档文本结构、权限和应用对文本接口的支持。“兼容复制模式”是正常的降级路径，不代表所有取词都不可用；该模式会更新系统剪贴板。

## 4. AI 语境释义

### 为什么使用它？

传统词典列出多个义项，读者需要自己排除。AI 根据当前句子中的用法，提供更有针对性的解释，同时保留本地词典供对照。

返回内容包括词形、词性、中英文含义、原文依据、置信度和歧义提示。置信度是模型自身的判断，不是经过校准的准确率；语境短、句子复杂时尤其需要核查。

### 如何配置？

进入“设置 → AI 语境释义”：

1. 打开“在取词浮窗中显示 AI 按钮”。
2. 填写服务商提供的 **OpenAI 兼容 API 地址**。通常填写兼容接口的基础地址，例如 `https://example.com/v1`；程序会补上 `/chat/completions`，也接受完整的该接口地址。这只是格式示例，不是可用服务。
3. 填写服务商提供的 **模型 ID**，不是模型的宣传名称。
4. 输入 **API Key**，点击“保存配置”。密钥保存到当前 Windows 用户的安全凭据中。
5. 点击“测试连接”，确认接口能返回程序需要的结构化释义。

远程 API 必须使用 HTTPS；本机服务可使用 localhost 或 127.0.0.1 的 HTTP 地址，但仍需满足程序的接口、模型和密钥配置要求。

配置后，在能取得语境的应用中选词、按取词快捷键，再点击浮窗的 AI 按钮。仅开启开关或打开浮窗不会自动发起语境分析；“测试连接”会主动发送示例请求。

### 使用限制与隐私

- 兼容复制模式没有语境，不提供 AI 释义；先确认不是该模式，再排查 AI 配置。
- 点击 AI 时发送选中词和最多约 500 个字符的附近语境，不会整本上传词典或整篇文档。
- 外部 AI 需要可访问的服务，可能产生由服务商决定的费用；离线词典查词不受 AI 是否开启影响。
- 不要发送个人隐私、保密工作材料或其他无权提供给服务商的文本。
- AI 可能误判词性、义项或依据。请结合原句和可靠词典检查，不把结果当作确定事实。
- 不需要 AI 时关闭其开关；可在设置中删除已保存的 API Key。

## 5. 收藏、阅读设置与托盘

主窗口和浮窗使用同一份收藏记录，可在“词汇本”中查看收藏与相关学习记录。

通过查词页面的 `Aa` 或“设置 → 阅读”调整字号，所有词典共用阅读比例。更改字号会导致文本重新排版。

“设置 → 关闭主窗口时”提供“直接退出”和“隐藏到托盘”。隐藏后程序继续运行，可从系统托盘恢复；右键托盘图标可彻底退出。屏幕取词需要程序仍在运行。

## 6. 备份与换电脑

在“设置 → 数据与诊断”选择“导出学习数据”或“恢复学习数据”。

- 导出包含历史、收藏、复习进度和阅读字号。
- 不包含词典文件、词典库配置或 AI API Key。
- 恢复会用备份记录替换当前学习记录；恢复前先导出当前数据。词典文件和词典库不会改变。
- 换电脑时还需另外复制合法持有的词典、重新导入，并重新设置 AI 和取词快捷键。

便携包免安装，但设置与学习数据存放在 Windows 用户应用数据目录中，不应只复制程序文件夹就认为完成了个人数据迁移。

## 7. 常见问题

- **词条空白**：确认 WebView2 Runtime 可用，原词典位置未改变，MDX/MDD 与附带资源完整。
- **找不到单词**：核对浮窗实际取得的文字、查找范围，以及目标词典是否启用且可以访问；尝试手动输入单词。
- **取词开关无法开启**：改选设置中提供的快捷键，确认程序和系统托盘正常运行。
- **PDF 无法取词**：先尝试在阅读器里手动复制。如果文档不可复制或是扫描版，当前文字取词可能无法工作；可手动输入查询。
- **浮窗没有 AI 按钮**：确认开关与配置已保存；如果只有复制选词而没有上下文，这是预期限制。
- **AI 超时或返回错误**：检查网络、API 地址、模型 ID、密钥和服务可用额度；部分兼容接口或模型不返回所需格式。
- **喇叭没有声音**：检查配套 MDD、系统音量和音频输出设备；不是每个词典都包含真人发音。
- **需要报告故障**：在“设置 → 数据与诊断”保存诊断报告。分享前检查是否包含不希望公开的本地路径或信息，勿附上 API Key 或无权分发的词典。
